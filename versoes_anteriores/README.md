# Versões anteriores

Esta pasta preserva snapshots importantes do **Painel de Compras** sem interferir na versão publicada em `main`.

- [`PaineldeCompras_v1_antes_importacao_arquivos_separados/`](./PaineldeCompras_v1_antes_importacao_arquivos_separados/) — versão anterior à correção que passou a reconhecer `Saldo.xlsx`, `consolidado3meses.xls` e `zerado.xlsx` como arquivos separados.

Os snapshots contêm o código-fonte, manifestos e artefatos de build daquele momento. Eles não contêm planilhas reais, históricos JSON, credenciais ou dados importados de usuários.
